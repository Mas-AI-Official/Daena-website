Enterprise-DNA Layer - Deep Dive

Comprehensive technical documentation for Daena's Enterprise-DNA governance and portability layer - providing complete audit trails, tenant policies, and automatic threat detection.

Overview

Enterprise-DNA is Daena's governance and portability layer built on top of NBMF. It provides complete audit trails, tenant policies, Merkle-notarized lineage, and immune threat detection for enterprise-grade operations. Enables safe cross-tenant learning and enterprise-grade auditability.

Four Core Components

🧬 Genome

Purpose: Agent capability schema

Features: Versioned behaviors per agent/department

Function: Defines what each agent can do and how capabilities evolve over time

⚙️ Epigenome

Purpose: Tenant/organization policies

Features: Feature flags, SLO/SLA, legal constraints

Function: Controls how agents behave based on organizational requirements

📜 Lineage

Purpose: Provenance and audit trail

Features: Merkle-notarized promotion history

Function: Complete audit trail with pointers into NBMF ledger

🛡️ Immune System

Purpose: Threat detection & response

Features: Prompt injection detection, quarantine/rollback

Function: Automatic threat detection wired to TrustManager

Merkle-Notarized Lineage

Every memory promotion in NBMF creates a cryptographically verified lineage record:

  • Merkle hash of the promotion event
  • Pointer to parent lineage record (chain)
  • NBMF ledger transaction ID
  • Timestamp and metadata

Latency: p95: 1.2ms for lineage recording

Immune System & Threat Detection

The Immune system automatically detects and responds to threats:

  • Prompt Injection Detection: Pattern-based detection with ML-ready scoring
  • Threat Levels: LOW, MEDIUM, HIGH, CRITICAL
  • Response: Automatic quarantine, quorum requirements, trust score adjustments
  • Latency: p95: 5ms for threat detection and response

Integration with NBMF

Enterprise-DNA hooks into NBMF promotion pipeline:

  • L2Q → L2 promotion: Lineage recorded automatically
  • L3 → L2 promotion: Lineage chain extended
  • L1 → L2 promotion: Lineage with hot-to-warm transition

All promotions are cryptographically verified and audit-ready.
