NBMF Memory System - Deep Dive

Comprehensive technical documentation for Daena's Neural-Backed Memory Fabric (NBMF) - the patent-pending memory architecture that delivers 94.3% storage savings† with 100% exact match (lossless mode)† or 95.28% similarity (semantic mode)†.

† Internal benchmarks. See Benchmarks & Technical Documentation section below for full methodology.

Overview

NBMF (Neural-Backed Memory Fabric) is Daena's patent-pending 3-tier memory architecture that intelligently compresses and tiers memory based on usage patterns. Unlike traditional AI systems that store everything in expensive vector databases, NBMF delivers 60%+ cost savings† while maintaining high accuracy.

† Internal benchmarks. See Benchmarks & Technical Documentation section or methods & reproducibility page for details.

3-Tier Architecture

🔥 L1 Hot Memory

Purpose: Fast-access recent items

Latency: p95: 0.65ms†

Content: Vector embeddings, active decision-making data

Retention: Recent items, frequently accessed

💾 L2 Warm Memory

Purpose: Compressed medium-term storage

Latency: p95: 2.5ms†

Technology: CAS + SimHash compression

Savings: 60%+ cost reduction†, semantic fidelity preserved

❄️ L3 Cold Memory

Purpose: Highly compressed long-term archives

Latency: p95: 15ms†

Content: Summarized archives, complete retention

Efficiency: Maximum compression, minimal storage

CAS + SimHash Technology

Content-Addressable Storage (CAS): Deduplication at the content level, eliminating redundant storage of identical or near-identical content.

SimHash: Locality-sensitive hashing for near-duplicate detection, enabling semantic similarity matching.

Combined Effect: 94.3% storage savings† in lossless mode, 74.4% savings† in semantic mode.

† Internal benchmarks. See Benchmarks & Technical Documentation section or methods & reproducibility page for methodology.

Hardware Acceleration

NBMF is optimized for multiple compute devices:

  • CPU: Universal fallback, 0.65ms p95 encode latency†
  • GPU: Real-time acceleration, 2-5× latency reduction†
  • TPU / Google TPUs: Supports modern Google Cloud TPUs with batch-parallel acceleration. Measured batch throughput gains depend on model and shape.†

Automatic device detection and routing - zero configuration required.
